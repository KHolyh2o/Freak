# Freak 프로젝트 전역 규칙 (AGENTS.md)

이 문서는 AI가 Freak 프로젝트를 작업할 때 반드시 기억해야 하는 영구적인 규칙과 제약사항을 담고 있습니다.

## 🗺️ 맵 제작 규약 (CSV Map Data Rules)
맵을 CSV로 절차적/수동으로 생성할 때는 **반드시** 아래의 규칙을 엄격하게 지켜야 합니다.

1. **필수 블록:** 맵에는 반드시 1개의 `Start` 블록과 1개의 `End` 블록이 존재해야 합니다.
2. **장애물 배치 (중첩 허용):** `Tree`, `Box`, `Stone` 등의 장애물은 바닥(`Floor`) 위에 설치되는 개념입니다. 따라서 CSV 파일 내에서 **바닥 블록과 동일한 x, z 좌표를 가져야 합니다.** (코드 내 `MapGenerator.cs`에서 렌더링 시 자동으로 y를 +1 올려줍니다.)
3. **CSV 포맷:** `x,z,y,type,extraOption,cost,tags`
4. **회전 방향:** `Start`와 `End` 블록의 바라보는 방향은 `extraOption` 열에 각도(0, 90, 180, 270)로 입력합니다.
5. **최대 코스트 제한:** 스테이지의 코스트 제한은 `Start` 블록의 `cost` 열에 정수로 명시합니다.
6. **AI 스킬 태그:** 스테이지가 요구하는 학습 스킬(`Sequence`, `Function`, `If`, `While`, `Spatial`, `ObstacleAvoidance`)은 `Start` 블록의 7번째 열(`tags`)에 기입합니다. 파이프(`|`)로 여러 개 조합 가능합니다.
7. **기획 의도:** 스테이지 1~5는 기초 학습 느낌(조작과 공간 감각), 그 이후 스테이지부터는 배운 것을 복합적으로 활용(함수, 조건문, 반복문)하는 컨셉으로 설계합니다.

## 🎮 코어 엔진 및 커맨드 시스템 규약 (Core & Command Rules)
커맨드 실행 로직이나 UI를 수정할 때는 다음 구조와 원칙을 반드시 숙지해야 합니다.

1. **커맨드 자료구조 (`CommandBlock` 객체 기반):**
   - 명령어는 단순 Enum이 아닌 `CommandBlock` 인스턴스로 관리됩니다.
   - `If`, `While` 제어문 블록은 `innerCommandCount`(범위에 포함될 블록 수), `conditionObstacle`(장애물 종류), `conditionExpectedState`(참/거짓 조건) 데이터를 갖습니다.
2. **다중 함수 시스템 (F1, F2, F3):**
   - 여러 개의 함수 패널을 `functionLists` (`List<List<CommandBlock>>`)로 묶어 관리합니다.
   - 메인 패널의 `CallFunction` 블록을 통해 해당 함수에 들어있는 커맨드들을 순차적으로 실행(건너뛰기/반복 포함)할 수 있습니다.
3. **글로벌 코스트(Cost) 계산 방식:**
   - 맵 파일(`Start` 블록)에서 지정된 `maxCommandCost`는 전체 게임에서 허용되는 명령어 코스트의 '총합'입니다. 메인 창과 모든 함수 창에 들어간 코스트가 이 값을 초과할 수 없습니다. (함수 패널별 별도 한도 없음)
   - **메인 패널 코스트:** 메인 패널에 배치된 블록 1개당 1코스트로 계산됩니다. (If, While, CallFunction 등의 제어/함수 블록 자체도 1코스트입니다).
   - **함수 패널 코스트:** 함수 패널(F1, F2 등) 내부에 명령어가 1개라도 존재한다면, **`함수 선언 비용(1)` + `내부 명령어 개수`** 만큼 코스트가 증가합니다. 
   - *예시:* 메인 창에 명령어 2개, F1 창에 명령어 3개가 있다면 총 코스트는 `2 + (1 + 3) = 6`이 됩니다. 만약 F2 창이 비어있다면 F2는 코스트를 0 소모합니다.
4. **커맨드 UI 편집 규칙:**
   - **패널 선택 (Active Panel):** 텅 빈 슬롯(배경)을 클릭하면 해당 패널이 활성화(activeListIndex 변경)되어 커맨드가 입력됩니다.
   - **중간 삽입 (Insert):** 기존 블록을 좌클릭하여 선택하면, 그 위치(`insertIndex`)에 새 커맨드가 끼워 넣어지고 기존 블록들은 뒤로 밀려납니다.
   - **범위 지정 (Scope Edit):** 제어문의 수정 버튼을 누르고 끝날 지점의 블록을 클릭하여 범위를 지정하며, 지정이 끝나면 삽입점은 괄호 바로 뒤로 자동 이동합니다.
   - **우클릭 삭제:** 블록을 우클릭하면 리스트에서 삭제되고 빈자리가 자동으로 당겨집니다.
