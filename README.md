# 🎮 Freak (어린이 코딩 교육 게임)

![Unity](https://img.shields.io/badge/Unity-2022.3.62f3-black?style=flat-square&logo=unity)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS-lightgrey?style=flat-square)

**Freak**는 아이들이 프로그래밍의 기본 개념(순차, 반복, 조건, 함수)을 쉽고 재미있게 학습할 수 있도록 돕는 **3D 쿼터뷰 퍼즐 어드벤처 게임**입니다.

---

## 🎯 기획 의도 및 필요성
현대 사회에서 코딩은 필수적인 소양이 되었지만, 텍스트 위주의 기존 코딩 교육은 어린이들이 흥미를 느끼기 어렵고 직관적이지 않습니다. **Freak**는 스크래치(Scratch)나 엔트리(Entry) 같은 블록 코딩의 장점을 살리면서, 이를 **3D 공간 기반의 퍼즐 게임**으로 승화시켜 아이들이 게임을 플레이하듯 자연스럽게 컴퓨팅 사고력(Computational Thinking)을 기를 수 있도록 기획되었습니다.

## 🕹️ 핵심 플레이 방식
- **3D 공간 지각:** 마우스를 드래그하여 카메라를 회전시키고 입체적인 맵을 관찰하며 목적지(도착점)까지의 경로를 구상합니다.
- **블록 코딩 시스템:** UI 패널에 명령어 블록(앞으로 가기, 회전, 조건문, 반복문 등)을 드래그 앤 드롭으로 배치합니다.
- **알고리즘 실행:** 조립한 커맨드를 실행하면 플레이어 캐릭터가 맵의 장애물을 피해 명령어대로 움직입니다.

## ✨ 주요 특징 및 차별점
1. **AI 어시스턴트 기능 도입:** 
   퍼즐이 막혔을 때, 게임 내 AI에게 힌트를 요청할 수 있어 혼자서도 좌절하지 않고 학습을 이어나갈 수 있습니다.
2. **함수(Function) 패널 활용:** 
   F1, F2 등 별도의 함수 패널을 지원하여 복잡한 반복 동작을 하나의 함수로 묶어 호출하는 등, 고급 프로그래밍 설계 기법을 직관적으로 배울 수 있습니다.
3. **입체적 상호작용:** 
   단순 2D 평면이 아닌 3D 환경에서 장애물(나무, 박스, 돌 등)을 회피하며 공간 감각과 알고리즘을 동시에 자극합니다.

## 🛠️ 현재 버전의 한계 및 향후 계획 (Known Issues & Future Works)
현재 버전(Prototype/Beta)에서는 다음과 같은 기능적 한계와 미완성된 요소들이 있으며, 추후 업데이트를 통해 개선될 예정입니다.

- **스테이지 선택 UI 미구현:** 현재 스테이지 선택 화면의 버튼들이 모두 동일한 이미지로 되어 있어 몇 번 스테이지인지 직관적으로 구분하기 어렵습니다.
- **텍스트 코드 변환 결과창 미완성:** 스테이지를 성공적으로 클리어했을 때, 플레이어가 조립한 블록 커맨드가 실제 텍스트 코드(C#, Python 등)로는 어떻게 작성되는지 보여주는 시각적 피드백 기능이 아직 완성되지 않았습니다.
- **언어 및 스토리 미완성:** 다국어 지원 및 인게임 스토리가 아직 준비되지 않아, 설정창의 '텍스트(자막) On/Off 기능'이 현재 작동하지 않습니다.
- **AI 어시스턴트 서버 불안정:** 인게임 AI 힌트 기능 사용 시, 연결된 AI 서버의 상태에 따라 간헐적으로 응답이 지연되거나 먹통이 되는 현상이 발생할 수 있습니다.
- **크리에이티브 모드(맵 에디터) 고도화:** 현재 기능적으로만 구현된 유저 창작 모드를 다듬어, 플레이어가 직접 맵을 만들고 공유할 수 있는 환경을 구축할 계획입니다.
- **레벨 시스템 개선:** 튜토리얼부터 복합 알고리즘 응용까지 이어지는 난이도 곡선과 스테이지 레벨 디자인을 세분화할 예정입니다.
